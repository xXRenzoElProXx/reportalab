**20–28 s:** Enviar y copiar el código de seguimiento. Texto: «Sin registro de usuario».

**28–44 s:** Volver al panel del personal, abrir la incidencia, añadir una nota y actualizar el estado. Texto: «Gestión centralizada».

**44–55 s:** Consultar el mismo código y mostrar el nuevo estado sin la nota interna. Texto: «Seguimiento sin cuenta».
